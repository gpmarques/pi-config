# Web access

This directory is a documentation-only reference. The implementation lives externally and is not vendored into `pi-config`:

**→ [nicobailon/pi-web-access](https://github.com/nicobailon/pi-web-access)**

It replaces this catalogue's former local `web-search` and `web-fetch` extensions with an external Pi package for web search and content retrieval. Upstream also documents source checking and specialized GitHub, PDF, image, YouTube, and local-video handling.

Install it with the command currently documented upstream:

```bash
pi install npm:pi-web-access
```

Treat the [upstream README](https://github.com/nicobailon/pi-web-access#readme) as authoritative for current installation, configuration, tools, requirements, and any future update guidance. This stub contains no executable implementation or local dependencies.
